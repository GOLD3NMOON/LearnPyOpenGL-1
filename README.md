# Learn LWJGL

Instale com pip
```py
pip install PyOpenGL PyOpenGL_accelerate glfw numpy Pillow PyGLM
```  
instale com [uv](https://docs.astral.sh/uv/)
```py
uv add PyOpenGL PyOpenGL_accelerate glfw numpy Pillow PyGLM
```
Rode com
```py
python3 src/main.py
```

Recomendação, use [Ambiente virtual](http://docs.python.org/3/library/venv.html)
